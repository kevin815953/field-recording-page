# 錄下來以後呢？

莊勝凱的田野錄音簡報。包含 15 頁、照片、原始音訊、影片與 LOOM / SHATTER。

## 發布

將本目錄的檔案及 `assets`、`tools` 資料夾上傳到 repository 根目錄（不要只上傳 ZIP）。
在 Settings → Pages 選 Deploy from a branch → main → /(root) → Save。
發布完成後網址為 https://kevin815953.github.io/field-recording-page/ 。

音訊維持原始品質。大檔分成每片不超過 20 MiB 的素材，播放器自動接回完整檔案，方便用 GitHub 網頁上傳。
頁面切換時才下載該頁素材；第一次開啟大型錄音頁可能需要等待。

方向鍵換頁、F 全螢幕、空白鍵播放／暫停。照片與播放器操作同離線版。
一般訪客不顯示編輯按鈕。加上 `?edit=1` 可在自己的瀏覽器編輯及匯出備份。
這些編輯不會自動更新 GitHub 上的公開內容。

更新公開內容時，重新轉換備份並替換 deck.json 與素材。素材與排版資料不會只存在發布者的瀏覽器。

原 MOV 影片以原有 H.264 / AAC 音畫重新封裝為 MP4，沒有重新編碼。

此包是線上發布版，請上傳後從 GitHub Pages 開啟；離線展示可繼續使用原 v14。
